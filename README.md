# Enrutamiento avanzado en Android

Práctica de la Unidad 2 · Módulo 0489 (DAM): app de notas con Navigation Component, SafeArgs y Deep Links, escrita en Java.

`EnrutamientoAvanzado.zip` contiene el proyecto de Android Studio sin la carpeta `build`.

- Pantalla 1 **Nueva nota**: título y prioridad, con validación.
- Pantalla 2 **Detalle de la nota**: recibe los datos con SafeArgs y vuelve con `popBackStack()`.
- Pantalla 3 **Confirmación** (ampliación 3): vuelve al inicio con `popUpTo`.
- Deep link: `notas://detalle/{tituloNota}`

Las respuestas a las preguntas están en `Respuestas_Entrega.md`, dentro del zip.
